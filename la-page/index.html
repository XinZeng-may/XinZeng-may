② 导入学习档案

在新电脑、手机或其他浏览器中打开本站，导入旧的 JSON 文件。默认合并现有数据，不覆盖已有文章。

提示：普通 CSV 导出只有词汇，JSON 完整备份才同时包含文章、翻译和练习。换网址或从本地 HTML 改到 Netlify 时，浏览器不会自动迁移数据，需要使用备份导入。
